# Ad Creative

Expert ad creative generation and iteration for paid social and search campaigns.

## Before Starting

Check for product marketing context first (GTM doc, positioning, ICP). Then gather:

1. **Platform & Format** — which platforms, aspect ratios, placements
2. **Product & Offer** — what's being promoted, key differentiator, landing page
3. **Audience & Intent** — ICP, pain points, awareness level
4. **Performance Data** — if iterating, top/bottom performers with metrics
5. **Constraints** — brand voice, compliance restrictions, budget tier

## How This Skill Works

**Mode 1: Generate from Scratch**
1. Define 3–5 distinct angles (each taps a different motivation)
2. Generate variations per angle (word choice, specificity, tone, structure)
3. Validate against platform character limits
4. Organize for upload

**Mode 2: Iterate from Performance Data**
1. Analyze winners — themes, structures, word patterns
2. Analyze losers — flat themes, underperforming patterns to avoid
3. Generate new variations — double down on winners, test new angles
4. Document the iteration (round number, date, patterns, new tests)

## Platform Specs

### Google Ads (RSA)
| Element | Limit | Qty |
|---------|-------|-----|
| Headline | 30 chars | Up to 15 |
| Description | 90 chars | Up to 4 |
| Display URL path | 15 chars each | 2 paths |

Rules: Headlines must work independently and in any combination. Include keyword-focused, benefit-focused, and CTA headlines.

### Meta (Facebook/Instagram)
| Element | Limit | Notes |
|---------|-------|-------|
| Primary text | 125 chars visible (2,200 max) | Front-load hook |
| Headline | 40 chars recommended | Below image |
| Description | 30 chars recommended | Below headline |

### LinkedIn
| Element | Limit | Notes |
|---------|-------|-------|
| Intro text | 150 chars recommended (600 max) | Above image |
| Headline | 70 chars recommended (200 max) | Below image |
| Description | 100 chars recommended (300 max) | Some placements |

### TikTok
| Element | Limit | Notes |
|---------|-------|-------|
| Ad text | 80 chars recommended (100 max) | Above video |
| Display name | 40 chars | Brand name |

### Twitter/X
| Element | Limit | Notes |
|---------|-------|-------|
| Tweet text | 280 chars | Core ad copy |
| Headline | 70 chars | Card headline |
| Description | 200 chars | Card description |

## Writing Quality Standards

**Strong headlines:**
- Specificity ("Cut reporting time 75%" not "Save time")
- Benefits over features
- Active voice
- Numbers when possible

**Headlines to avoid:**
- Unrecognized jargon
- Unsupported superlatives
- All caps or excessive punctuation
- Undeliverable clickbait

**Descriptions should:**
- Complement, not repeat headlines
- Add proof points
- Handle objections
- Reinforce CTAs
- Add genuine urgency when applicable

## Batch Generation Workflow

- **Wave 1:** Core angles (3–5 angles, 5 variations each)
- **Wave 2:** Extended variations on top 2 angles
- **Wave 3:** Wild card angles (contrarian, emotional, hyper-specific)

**Quality filter checklist:**
- Remove character limit violations
- Remove near-duplicates
- Flag compliance risks
- Verify headline/description coherence

## Common Mistakes

1. Headlines that only work in specific combinations
2. Ignoring character limits
3. Excessive similarity across variations
4. Missing CTA-focused headline
5. Generic descriptions
6. Iterating by intuition without metrics
7. Testing multiple variables simultaneously
8. Retiring creative before 1,000+ impressions

## Output Format

Organize by angle. Include character counts. Flag anything over limit with a trimmed alternative.

For bulk: provide CSV with headline variants, description variants, platform designation.

For iteration: include performance summary, new creative, and pause/scale/test recommendations.
